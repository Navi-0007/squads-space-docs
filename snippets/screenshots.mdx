{/*
  SCREENSHOT REGISTRY
  ═══════════════════════════════════════════════════════
  Central file for all screenshot URLs used across docs.

  S3 STRUCTURE:
  public-assets/public-docs/
  ├── getting-started/
  ├── players/
  ├── organizer/
  │   ├── dashboard/
  │   ├── tournaments/
  │   ├── matches/
  │   ├── groups/
  │   ├── live-scoring/
  │   ├── overlays/
  │   ├── scrims/
  │   └── clubs/
  └── how-to/

  HOW TO USE:
  1. Take the screenshot (see SCREENSHOT_GUIDE.md for what to capture)
  2. Upload to S3 at: public-assets/public-docs/[section]/[filename].png
  3. Set the S3_BASE below to your bucket URL
  4. Replace "" with the filename (e.g., "become-organizer-landing.png")
  5. The full URL is built automatically: S3_BASE + folder + filename

  ADDING A NEW SCREENSHOT:
  1. Add a new export line below in the correct section
  2. Upload the file to the matching S3 folder
  3. Set the filename in the export
  4. In the page MDX, import it: import { ss_my_screenshot } from '/snippets/screenshots.mdx'
  5. Use it: <Frame caption="Description"><img src={ss_my_screenshot} alt="Description" /></Frame>
  ═══════════════════════════════════════════════════════
*/}

{/*
  ── S3 BASE URL ────────────────────────────────────────

*/}
