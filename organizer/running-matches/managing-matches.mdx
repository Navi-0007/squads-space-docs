After your groups are locked, you can start creating and managing matches. Groups (Elimination) and pairings (Round Robin) share the same match management layout.

## Creating Matches

From a group or pairing page, click **Create Matches**:

1. Specify how many matches you want (up to 8)
2. You can set different match counts per group — not every group has to have the same number
3. Each match appears in the match selector (Match 1, Match 2, etc.)

## Match Lifecycle

Each match moves through these statuses, shown with a colored indicator:

- **Not Scheduled** — match created, no time set
- **Scheduled** — time and map are set, waiting to start
- **Live** — match is in progress (green pulsing indicator)
- **Completed** — match finished, results uploaded
- **Cancelled** — match was cancelled

Use the action buttons to progress: **Set Schedule** → **Start Match** → **End Match** (or **Cancel** at any point).

## Setting the Map

For each match, select which Free Fire map will be played from the dropdown. This helps players prepare and know what to expect.

## Room ID & Password

Each group and pairing page has a room ID and password section. Enter the custom room credentials here.

Players can only see room credentials once the match status is **Live**. Before that, they see a lock icon with a message explaining that credentials will appear when the match starts.

> **Tip:** Enter room credentials before starting the match. When you click "Start Match", players immediately see the room ID and password — no delay.

## Entering Results

After a match finishes, you have two ways to enter scores:

### Smart Results (Recommended)

Click the **Smart Results** button (sparkles icon) in the group page header:

1. Upload a screenshot of the in-game results screen
2. The system reads placements and kills automatically
3. Review the extracted scores, adjust if needed
4. Confirm to save

### Manual Entry

Open the match results section:

1. You'll see a table with all teams in the group
2. If UID/IGN is enabled, choose your entry mode:
   - **Team Kills** — enter total kills per team
   - **Player Kills** — enter kills for each individual player (team total auto-sums)
3. For each team, enter:
   - **Placement** — their finishing position
   - **Kills** — team total or per-player, depending on your chosen mode
4. Click **Save**

Points are calculated automatically using your point table (kill points + placement points = total). The leaderboard updates instantly.

> **Tip:** Smart Results is fastest when you have a clear screenshot. Use manual entry when you need to make precise adjustments or when the screenshot is unclear.

## Announcements

Each group and pairing page has an announcements section. Post updates for participants in that group — schedule changes, delays, map changes, or any other info. Players see these in their Match Hub.

## Live Scoring

If you're streaming, you can enter scores live and they'll update the stream overlay automatically. See [Live Scoring](/organizer/live-streaming/live-scoring) for the streaming workflow.

## Managing at Scale

For stages with many groups, navigating to each group individually can be slow. Use [Mass Operations](/organizer/running-matches/mass-operations) to create matches, set schedules, and enter results across all groups from a single page.
