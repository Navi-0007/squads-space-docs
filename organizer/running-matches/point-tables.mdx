The point table defines how scores are calculated in your tournament or scrim. You set it during the creation wizard (Step 2: Game Configuration), and it applies to all matches across the event.

## How Points Work

Each team's total score for a match is calculated as:

**Total Points = Kill Points + Placement Points**

Points accumulate across all matches in a group (Elimination) or across all pairings (Round Robin). The leaderboard ranks teams by their total cumulative points.

## Kill Points

Set how much each kill is worth. For example, 1 kill = 1 point. This applies to the total team kill count per match.

If UID/IGN is enabled and you use Player Kills mode when entering results, individual kills are tracked per player — but the team total still determines kill points.

## Placement Points

Assign points for each finishing position in a match. You define how many points 1st place gets, 2nd place, 3rd place, and so on — all the way through your group size (e.g., 1st through 12th for a 12-squad group).

A typical placement table for Squad mode:

| Position | Points |
|----------|--------|
| 1st | 12 |
| 2nd | 9 |
| 3rd | 7 |
| 4th | 5 |
| 5th | 4 |
| 6th | 3 |
| 7th | 2 |
| 8th–12th | 0 |

You can customize this however you like — use FFIC/FFWS official point tables or create your own.

> **Tip:** The FFIC 2024 point table uses 1 point per kill and 12/9/8/7/6/5/4/3/2/1/0/0 for placement. This is a good starting point for competitive events.

## Tiebreaker Rules

When teams are tied on total points, the tiebreaker determines who ranks higher. You choose one of two priorities:

- **Placement First** — Points → Placement → Kills → Matches played. Teams with better average placement rank higher.
- **Kills First** — Points → Kills → Placement → Matches played. Teams with more total kills rank higher.

> **Tip:** Most competitive tournaments use "Placement First" — it rewards consistent performance. Use "Kills First" for scrim-style events where aggression matters more.

## Where Points Are Used

- **Match results** — when you enter placement and kills, the system calculates points automatically
- **Group leaderboards** — cumulative standings within a group
- **Stage leaderboards** — combined standings across all pairings (Round Robin)
- **Stream overlays** — leaderboard updates live during broadcast
- **Smart Results** — points are calculated automatically when you upload a screenshot
